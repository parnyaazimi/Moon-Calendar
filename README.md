# 🌙 Moon Calendar

A WPF-based desktop application developed as part of a university **Advanced Programming** course project.

## 📌 About the Project

Moon Calendar is a desktop application built using C# and Windows Presentation Foundation (WPF).

The project is planned to be developed in multiple phases. **Phase 1 has been completed**, and the remaining phases are planned for future development.

## 🛠️ Technologies Used

- **C#** — Programming language
- **WPF (Windows Presentation Foundation)** — Desktop user interface framework
- **XAML** — User interface layout and design
- **Visual Studio** — Development environment

## ▶️ Getting Started

To open the project locally:

1. Clone this repository:

   ```bash
   git clone https://github.com/parnyaazimi/Moon-Calendar.git
   ```

2. Open `Projcet_WPF.sln` in Visual Studio. The solution file is located inside the `Projcet_WPF` folder.

3. Build and run the application using Visual Studio.

**Requirements:** Windows and Visual Studio with WPF development support.
